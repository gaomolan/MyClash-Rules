# ADR-004 Smart 线定位

- 状态：研究建议（待所有者确认）
- 日期：2026-10-28
- 关联：R-009（SRC-1003）、WP-10 Smart 现状（SRC-1008 §5）、WP-5 smart 分档结论（SRC-1004 §7 拍板 7 的研究侧建议）

## 背景

Smart 组类型的供应链事实（WP-10 源码级核查）：官方 mihomo 主线 v1.19.33 对 lightgbm/smart 代码搜索 0 命中，主线不存在 smart 组；实现位于下游 fork lux5am/mihomo-smart，仅 Alpha 分支、唯一 Release 为 2025-09-17 Prerelease-Alpha、18 stars，无正式版节奏。用户测试机所用 Bettbox feat/smart-core 个人分支（KevinChen222）公开不可达，其内核来源、与 lux5am fork 的关系、6 个 Smart GUI 开关现状均未验证（否定性检索确认公开不可达）。脚本侧仅置 `uselightgbm=true`（默认关、opt-in），开启后内核按默认地址下载 Model.bin（vernesong Release），失败自动回退统计选路（T-09，2×2=4 低）；模型本身许可/训练数据未单独声明（LIC-11）。社区模板中的 smart 参数名与 fork 源码标签不完全同名，跨模板抄参数有静默失效风险。

## 选项

- **甲：并入主线**。smart 成为公开产物的正式功能面，与主线同等承诺。
- **乙：独立实验线**。smart 变体单独发布、单独标注，参数以 lux5am fork 源码标签为唯一基准，主线承诺不含 smart。
- **丙：弃用 smart 线**。回归官方组类型（url-test/load-balance），删除 smart 变体。

## 决定

采**乙**：smart 线定位为**独立实验线**，具体边界：

1. smart 变体不与主线同等承诺：发布说明明示其依赖非官方内核分支、内核来源与版本对应关系未完全验证；主线（Go 线 lite/full）的兼容性声明不覆盖 smart。
2. 参数基准唯一化：smart 参数集以 lux5am/mihomo-smart 源码标签为准逐项核名，禁止从社区模板转抄未核参数；fork 参数变更时以「fork 变更评审」处理（同上游精选逻辑）。
3. smart 线不出 lite 档（与 WP-5 建议一致）：Smart 人群为进阶人群，且其开关面已 +5，再分档只扩大发布与测试矩阵，与防漂移目标背反。
4. LightGBM 保持 opt-in 默认关；Model.bin 的许可未明状态在实验线文档中明示，不作合规背书。
5. 降级触发条件（任一成立即启动丙评估）：lux5am fork 停止维护超过两个官方主线大版本周期；feat/smart-core 构建被证实与 fork 源码不一致且无法对账；smart 参数语义出现破坏性变更且无迁移路径。

## 后果

- 正面：主线承诺面收敛到官方内核可验证范围（与 R-010 的处置同向）；实验线保留用户测试机的既有使用与探索价值，不因供应链不透明而一刀切；参数静默失效风险被基准唯一化封住主要入口。
- 负面：实验线成为长期「第二公民」，文档与支持口径须持续维护其边界（用户误把实验线当主线提问的成本由文档承担）；fork 若长期停滞，实验线将慢性死亡，降级触发条件即为此设。
- 与弃用案（丙）的关系：丙在证据上并非不可行（官方组类型可覆盖选路需求），但用户测试机正在使用 smart 全套且其 GBM 行为有待实测数据回收；在「实验线」定位下保留观察期，比立即弃用更符合证据现状；观察期无正向数据时，丙应被重新提起。
